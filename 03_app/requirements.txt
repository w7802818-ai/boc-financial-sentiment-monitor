# Bank of China Financial Information Monitoring — Streamlit app
# =============================================================
#
# Ranges are bounded to the versions this project was actually validated
# against. Streamlit Cloud resolves the newest version inside each range, so
# the bounds deliberately exclude releases with known breaking changes.
#
#   * streamlit >=1.49 is REQUIRED: the app uses `st.dataframe(width="stretch")`,
#     which replaced the deprecated `use_container_width` in 1.49. On <1.49 the
#     layout arguments would be rejected or warned about.
#   * transformers is capped at <6.0. The project is validated on 5.19.x;
#     `AutoModelForSequenceClassification` / `AutoTokenizer` APIs are stable
#     across 4.40-5.x but a future major could break loading.
#   * pandas is capped at <3.1. Validated on 3.0.6; avoids an untested bump.
#   * torch is CPU-only on Streamlit Cloud (no CUDA). The default wheel index
#     resolves to a CPU build automatically; no extra index URL is needed.
#
# Validated environment (2026-10):
#   python 3.12.10 | streamlit 1.65.0 | torch 2.14.1+cpu | transformers 5.19.0
#   pandas 3.0.6 | numpy 2.5.3 | plotly 7.1.0
